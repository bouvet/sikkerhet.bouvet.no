    <h3>Information Security</h3>
    <p>is about securing these aspects of an IT system:</p>
    <div class="home-kit">
      <div class="home-kit__item">
        <span class="home-kit__key">C</span>
        <span class="home-kit__term">Confidentiality</span>
        <span class="home-kit__desc">The data processed by the system should not be accessible to unauthorized individuals.</span>
      </div>
      <div class="home-kit__item">
        <span class="home-kit__key">A</span>
        <span class="home-kit__term">Availability</span>
        <span class="home-kit__desc">The functions offered by the system are available when users need them.</span>
      </div>
      <div class="home-kit__item">
        <span class="home-kit__key">I</span>
        <span class="home-kit__term">Integrity</span>
        <span class="home-kit__desc">The data processed by the system is correct.</span>
      </div>

  <article class="home-card">
    <h3>Security Champion</h3>
    <p class="home-card__lead">Are you, or do you want to be a hero?</p>
    <p>A Security Champion is a person who acts as a driving force and motivator for security work in a team or department/unit. Responsibility for security lies with the team as a whole, but as a Security Champion, you contribute to awareness and focus within the team.</p>
    <p>A good place to start, whether you are or want to be a hero, is our info package for Security Champions.</p>
